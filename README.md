# Parité

A Python analysis of gender parity among French members of parliament, an OpenClassrooms course project.

## About The Project

A command-line analysis script (`parite.py`) working on the `data/current_mps.csv` dataset, built for the OpenClassrooms course "Perfectionnez-vous en Python".

### Status

Finished, per the original README.

## Built With

- Python

## Getting Started

Run the analysis with:

```
python parite.py -d current_mps.csv
```
